Regression Lineaire

Module 1 : Fondamentaux ML Lecon 3/12 25 min Facile

Qu'est-ce que la Regression Lineaire?

La regression lineaire est l'algorithme fondamental de l'apprentissage automatique. Elle modelise la relation entre une variable dependante (cible) et une ou plusieurs variables independantes (features) en ajustant une equation lineaire aux donnees observees.

En termes simples, la regression lineaire trouve la "meilleure droite" qui passe a travers un ensemble de points. Cette droite minimise la distance entre les valeurs predites et les valeurs reelles.

y = w1x1 + w2x2 + ... + wnxn + b

Ou w represente les poids (coefficients), x les features, et b le biais (intercept). L'objectif est d'apprendre les valeurs optimales de w et b a partir des donnees d'entrainement.

Regression Lineaire Simple

La regression lineaire simple considere une seule variable explicative. L'equation se simplifie :

y = wx + b

La methode des moindres carres ordinaires (MCO) trouve les coefficients optimaux en minimisant la somme des carres des residus :

J(w, b) = (1/2n) * sum(yi - (wxi + b))²

Les formules analytiques pour les coefficients sont :

  • w = sum((xi - x̄)(yi - ȳ)) / sum((xi - x̄)²)
  • b = ȳ - w * x̄

Regression Multiple

En pratique, on utilise rarement la regression simple. La regression multiple considere p features :

Y = Xw + b

En notation matricielle, X est la matrice de design (n x p), w le vecteur de poids (p x 1), et Y le vecteur cible (n x 1). La solution analytique est :

w = (XTX)-1XTY

Cette formule est connue sous le nom de normal equation. Elle est exacte mais peut etre couteuse pour de grands jeux de donnees (complexite O(p³)).

Descente de Gradient

Pour les gros jeux de donnees, on utilise la descente de gradient, une methode iterative qui met a jour les poids progressivement :

w = w - alpha * dJ/dw
b = b - alpha * dJ/db

Ou alpha est le learning rate. Les gradients sont :

dJ/dw = -(1/n) * sum(x_i * (y_i - (wx_i + b)))
dJ/db = -(1/n) * sum(y_i - (wx_i + b))

Variantes de la Descente de Gradient

  • Batch GD : utilise toutes les donnees a chaque iteration. Stable mais lent.
  • Stochastic GD (SGD) : utilise un echantillon a la fois. Rapide mais bruit.
  • Mini-batch GD : compromis avec des lots de 32-256 echantillons.

Regularisation

La regularisation previent le surapprentissage en penalisant les poids trop eleves :

Ridge (L2)

J(w) = MSE + λ * sum(wi²)

La regularisation L2 resserre les poids vers zero sans les annuler. Elle est utile quand toutes les features sont potentiellement utiles.

Lasso (L1)

J(w) = MSE + λ * sum(|wi|)

La regularisation L1 peut annuler completement certains poids, agissant comme un selecteur de features.

Elastic Net

J(w) = MSE + λ1 * sum(|wi|) + λ2 * sum(wi²)

Combine les avantages de L1 et L2. Ideal quand les features sont correlees.

Metrics d'evaluation

  • MSE (Mean Squared Error) : erreur quadratique moyenne, penalise les grosses erreurs
  • RMSE (Root MSE) : racine carree du MSE, meme unite que la cible
  • MAE (Mean Absolute Error) : erreur absolue moyenne, plus robuste aux outliers
  • R² : proportion de variance expliquee (0 a 1, 1 = parfait)
  • Adjusted R² : penalise l'ajout de features inutiles

Hypotheses de la Regression

Points importants : La regression lineaire repose sur 4 hypotheses critiques qu'il faut toujours verifier :
  1. Linearite : la relation entre X et Y est lineaire
  2. Independance : les residus sont independants les uns des autres
  3. Homoscedasticite : la variance des residus est constante
  4. Normalite : les residus suivent une loi normale

Code Exemple

from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score
import numpy as np

# Donnees
X = np.random.rand(100, 3)
y = 2*X[:,0] + 3*X[:,1] - X[:,2] + np.random.randn(100)*0.1

# Split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# Regression lineaire
model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(f"Coefficients: {model.coef_}")
print(f"Biais: {model.intercept_}")
print(f"RMSE: {np.sqrt(mean_squared_error(y_test, y_pred)):.4f}")
print(f"R²: {r2_score(y_test, y_pred):.4f}")

# Ridge (L2)
ridge = Ridge(alpha=1.0)
ridge.fit(X_train, y_train)
print(f"Ridge R²: {ridge.score(X_test, y_test):.4f}")

# Lasso (L1) - peut annuler des features
lasso = Lasso(alpha=0.1)
lasso.fit(X_train, y_train)
print(f"Lasso coefficients: {lasso.coef_}")

Questions d'entretien frequentes

Q1 : Quelle est la difference entre regression lineaire et regression logistique ?

La regression lineaire predit une valeur continue (prix, temperature), tandis que la regression logistique predit une probabilite d'appartenance a une classe (spam/non-spam). La logistique utilise la fonction sigmoide pour mapper les sorties entre 0 et 1.

Q2 : Comment savoir si la regression lineaire est appropriate ?

Verifier les hypotheses : 1) Tracer les residus vs valeurs predites (linearite), 2) Test de Durbin-Watson (independance), 3) Test de Breusch-Pagan (homoscedasticite), 4) QQ-plot des residus (normalite). Aussi, calculer le R² et verifier la significativite des coefficients (p-values).

Q3 : Que se passe-t-il quand les features sont fortement correlees ?

C'est la multicolinearite. Les coefficients deviennent instables et difficilement interpretables. Solutions : 1) Supprimer une feature correlee, 2) Utiliser la PCA, 3) Appliquer Ridge (L2) qui stabilise les coefficients, 4) Calculer le VIF (Variance Inflation Factor).

Q4 : Lasso vs Ridge - quand utiliser quoi ?

Lasso quand vous suspectez que seules quelques features sont importantes (selection de features). Ridge quand la plupart des features contribuent. Elastic Net quand les features sont correlees et que vous voulez la selection de Lasso.

Q5 : Comment gerer les outliers en regression ?

1) Detection : Z-score, IQR, Cook's distance. 2) Traitement : suppression (si erreur), transformation (log), winsorization. 3) Modeles robustes : regression Huber, RANSAC, Theil-Sen qui sont moins sensibles aux outliers.
